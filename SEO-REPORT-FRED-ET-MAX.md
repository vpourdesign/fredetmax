## 6. SEO TECHNIQUE — WIX STUDIO

### Paramètres SEO Wix Studio à configurer

#### Titres et Meta
- **Chaque page** doit avoir un Title Tag unique (max 60 caractères) et une Meta Description unique (max 155 caractères).
- Dans Wix Studio : Pages → SEO Basics → remplir pour CHAQUE page.
- Ne jamais laisser les valeurs par défaut.

#### URLs
- Wix Studio permet des URLs personnalisées. Utiliser des slugs courts et descriptifs.
- Exemple : `/courtiers-immobiliers-blainville` (PAS `/page-1` ou `/copy-of-blainville`).
- Éviter les accents dans les URLs : `ste-therese` pas `sainte-thérèse`.

#### Redirections 301
- Si des pages sont renommées, configurer des redirections dans Wix : SEO Tools → URL Redirect Manager.

#### Sitemap XML
- Wix génère automatiquement un sitemap à `fredetmax.com/sitemap.xml`.
- Vérifier que toutes les nouvelles pages y apparaissent.
- Soumettre le sitemap dans Google Search Console.

#### Robots.txt
- Accessible à `fredetmax.com/robots.txt`.
- Vérifier qu'aucune page importante n'est bloquée.

#### Balises Alt sur les images
- **CRITIQUE :** Renommer et ajouter des balises alt descriptives à TOUTES les images.
- Exemple : `courtier-immobilier-blainville-fred-et-max.jpg` au lieu de `Copie de Fred&MAx12951.jpg`.
- Alt text : "Équipe Fred et Max, courtiers immobiliers à Blainville, Rive-Nord de Montréal".

#### Vitesse de chargement
- Wix Studio est limité côté performance. Pour optimiser :
  - Compresser toutes les images (WebP via Wix media manager).
  - Limiter les animations lourdes.
  - Limiter les polices personnalisées (max 2).
  - Utiliser le lazy loading natif de Wix.
  - Vérifier les Core Web Vitals dans Google Search Console.

## 11. STRATÉGIE BILINGUE — VERSION ANGLAISE COMPLÈTE DU SITE

### Pourquoi c'est critique pour le SEO

La Rive-Nord de Montréal attire de plus en plus d'acheteurs anglophones (relocalisation depuis l'Ontario, immigrants, familles bilingues). Parmi les concurrents analysés, seuls Gabriel Siciliano et Nicolas Boudreau offrent une version anglaise — c'est un avantage compétitif majeur à saisir.

**Avantages SEO d'un site bilingue :**
- Doubler le nombre de pages indexées (chaque page FR a son équivalent EN)
- Capturer des recherches en anglais ("real estate agent north shore montreal", "houses for sale Blainville", etc.)
- Améliorer l'expérience utilisateur pour les clients anglophones relocalisés
- Se positionner sur des mots-clés anglais moins compétitifs au Québec (moins de courtiers les ciblent)

### Architecture bilingue dans Wix Studio

Wix Studio supporte nativement le multilingue via **Wix Multilingual** :

```
Structure recommandée :
fredetmax.com/          → Page d'accueil FR (défaut)
fredetmax.com/en/       → Page d'accueil EN

fredetmax.com/courtiers-immobiliers-blainville
fredetmax.com/en/real-estate-agent-blainville

fredetmax.com/evaluation-gratuite
fredetmax.com/en/free-home-evaluation

fredetmax.com/vendre-votre-propriete
fredetmax.com/en/sell-your-property

fredetmax.com/acheter-une-propriete
fredetmax.com/en/buy-a-property
```

### Configuration technique Wix Multilingual

1. **Activer Wix Multilingual** dans le dashboard Wix.
2. **Balises hreflang** — Wix les génère automatiquement avec Multilingual. Vérifier que chaque page a :
   ```html
   <link rel="alternate" hreflang="fr-ca" href="https://www.fredetmax.com/courtiers-immobiliers-blainville" />
   <link rel="alternate" hreflang="en-ca" href="https://www.fredetmax.com/en/real-estate-agent-blainville" />
   ```
3. **Ne PAS utiliser de traduction automatique** — Chaque page EN doit être rédigée avec des mots-clés anglais spécifiques, pas une simple traduction Google.
4. **URLs anglaises distinctes** — Pas `/en/courtiers-immobiliers-blainville`, mais `/en/real-estate-agent-blainville`.
